# hexlet-vibecoding
Учусь вайбкодингу, тут будут мои эксперименты

## Эксперименты

- [Калькулятор калорий](calorie-calculator/index.html) — считает дневную норму калорий, БЖУ и индекс массы тела по формуле Миффлина — Сан Жеора. Чтобы открыть, скачайте файл `calorie-calculator/index.html` и откройте его в браузере.
- [Визитка IELTS Boost](ielts-landing/index.html) — страница приложения для подготовки к IELTS: ценности, примеры упражнений и форма «Узнать больше». Чтобы открыть, скачайте файл `ielts-landing/index.html` и откройте его в браузере.
